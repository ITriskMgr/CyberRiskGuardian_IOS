Setup

Create the “CRG Assistant” Shortcut (2 minutes, once)
  1. Open the Shortcuts app, tap +, and name the shortcut CRG Assistant exactly.
  2. Add the action Use Model (Apple Intelligence). Choose Private Cloud Compute for the best scenarios, or On-Device to keep everything on the iPhone. Do not choose ChatGPT for confidential work.
  3. Tap the request field and insert the Shortcut Input variable. If Shortcuts adds “Receive input from”, set it to Text.
  4. Add Copy to Clipboard with the model's Response.
  5. Add Stop and Output with the Response.
  6. Optional: add Show Notification “Result copied. Return to CRG.”
  7. Tap Test the Shortcut below.

Requires an iPhone with Apple Intelligence (iPhone 15 Pro or later), a recent iOS with the Use Model action, and Apple Intelligence turned on. Availability depends on language and region.

The app sends only the text shown in each request to your Shortcut. On-Device keeps it on the iPhone; Private Cloud Compute processes it on Apple servers without retaining it. AI output is an analytical hypothesis to validate: it never changes your numbers by itself.

Settings

Assessment

Appetite anchors: 0.1–0.2 very risk averse · 0.3 low · 0.5 neutral · 0.7 high · 0.8–0.9 very high. The factor is held constant across scenarios (1,000 by default).
